# Stata MCP 자동 설치 — Windows / Codex / Claude Desktop

**한국어** | [English](INSTALL.en.md)

## 준비

- 정상 실행되는 Stata와 유효한 라이선스. 검증 환경: StataNow 19.5 BE.
- 64비트 Python 3.11 이상. 검증 환경: Python 3.12.
- 같은 Windows PC에 설치된 Codex 또는 Claude Desktop과 인터넷 연결.
- Python·Stata·AI 앱 본체는 설치기에 포함되지 않습니다. 관리자 권한은 필요하지 않습니다.

## 설치

1. [GitHub v0.1.5](https://github.com/seokjinwoo/stata-mcp/releases/tag/v0.1.5)에서 `stata-mcp-0.1.5-windows-setup.zip`을 받습니다. 로그인 없이 받을 수 있습니다.
2. ZIP을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 선택합니다.
3. 압축을 푼 폴더에서 **설치.cmd**를 더블클릭합니다. `install.cmd`도 같은 기능입니다. 첫 화면에서 **1. 한국어 / 2. English**를 선택합니다. Enter의 기본값은 한국어입니다.
4. Python 환경과 패키지 준비가 끝나면 **1. Codex / 2. Claude Desktop / 3. 둘 다** 중 사용할 앱을 선택합니다. Enter의 기본값은 Codex입니다.
5. Stata가 여러 개이면 사용할 버전을 선택합니다. 자동 탐색되지 않으면 Stata 설치 폴더를 선택합니다.
6. 기존 `stata-local` 설정이 다르면 교체 안내가 표시됩니다. 교체할 때만 `Y`를 입력합니다. 다른 MCP 서버와 앱 설정은 보존하고 원본을 백업합니다.
7. 회귀분석·그래프 검사와 선택한 앱의 설정 등록이 끝나면 완료 안내가 나옵니다.
8. 선택한 앱을 **완전히 종료**했다가 다시 실행하고 새 대화에서 아래처럼 요청합니다.

> stata-local의 stata_status 도구를 호출해서 연결 상태를 확인해 줘.

이어 아래처럼 실제 예제를 요청할 수 있습니다.

> Stata 공식 hospdd 예제로 didregress (satis) (procedure), group(hospital) time(month)를 실행하고, 추정 결과와 stcolor 스킴의 estat trendplots 그래프를 보여 줘.

실행 코드와 기준 결과는 ZIP의 `examples/demo.do`, `examples/README.md`에 들어 있습니다. 설치 중 연결 검사는 인터넷 자료가 필요 없는 내장 auto 데이터로 수행합니다.

설치기 안내·메뉴·오류 메시지는 선택한 언어로 표시됩니다. Stata·패키지 관리자·운영체제의 원래 로그와 AI 앱의 언어 설정은 변경하지 않습니다.

## Claude Desktop 안내

Claude Desktop을 선택하면 기본적으로 `%APPDATA%\Claude\claude_desktop_config.json`의 `mcpServers`에 `stata-local`을 추가합니다. `command`, `args`, `env`만 사용하며 Codex 전용 설정은 넣지 않습니다.

Claude Desktop의 **Settings → Developer → Edit Config**에서 실제 설정 위치를 확인하세요. 앱 설치 방식에 따라 위치가 다르면 아래 `-ClaudeConfig` 옵션으로 해당 파일을 지정합니다. 브라우저의 claude.ai에 커넥터 URL을 입력하는 설치 방식이 아닙니다.

설정 등록과 표준 MCP 연결·분석·그래프 반환을 검사하지만, Claude 앱 안에서의 최종 도구 호출은 아직 미검증입니다. 앱 재시작 후 테스트해 주세요. 조직에서 로컬 MCP를 제한한 경우 관리자에게 문의하세요.

[공식 로컬 MCP 연결 안내](https://modelcontextprotocol.io/docs/develop/connect-local-servers)

## 설치 위치와 재실행

- 서버: `%LOCALAPPDATA%\StataMCP\envs\0.1.5`
- Codex 설정: `%CODEX_HOME%\config.toml`, CODEX_HOME이 없으면 `%USERPROFILE%\.codex\config.toml`
- Claude 설정: `%APPDATA%\Claude\claude_desktop_config.json`
- 분석 폴더: `%USERPROFILE%\Documents\StataAnalysis`
- 설치 검사 결과: 분석 폴더의 `installation-check`
- 설치 보고서: `%LOCALAPPDATA%\StataMCP\installation-result.json`
- 수동 병합용 Claude 예시: `%LOCALAPPDATA%\StataMCP\claude-desktop.local.json`
- 설정 백업: 각 설정 파일 옆의 `.before-stata-날짜.bak`

성공 후 ZIP과 압축 해제 폴더는 지워도 되지만 서버 환경과 Python 본체는 유지해야 합니다. 같은 버전 재설치는 환경을 재사용하며 동일 설정은 중복 등록하지 않습니다. 새 버전은 별도 환경에 설치하고 기존 stata-local 경로 교체를 확인합니다. 이전 환경을 자동 삭제하지 않습니다. 두 앱은 각각 독립적인 Stata 세션을 사용하므로 메모리의 데이터는 공유하지 않습니다.

## 오류 대응과 피드백

- Python을 찾지 못함: Python 3.12 64비트를 설치한 뒤 다시 실행합니다. 별도 위치는 `-PythonPath`로 지정합니다.
- Stata를 찾지 못함: `utilities\pystata`와 사용하는 에디션의 `StataBE-64.exe` 등 실행 파일이 있는 폴더를 선택합니다.
- 라이선스 오류: Stata 단독 실행을 먼저 확인합니다.
- 패키지 설치 오류: 인터넷·프록시·회사 정책을 확인합니다.
- 설정 문법 오류: 원본을 덮어쓰지 않습니다. 안내된 TOML/JSON 문법 오류를 수정한 뒤 재실행합니다.
- 설치 중단 후 잠금 오류: 실행 중인 다른 설치 창이 없는지 확인한 뒤 설치 폴더의 `install.lock` 또는 설정 옆 `.stata-install.lock`을 제거합니다.
- 앱에서 도구가 없음: 앱 완전 종료·재시작, 실제 설정 위치, 조직의 로컬 MCP 허용 여부를 확인합니다.

[GitHub Issues](https://github.com/seokjinwoo/stata-mcp/issues)에 Windows·Stata 버전, 선택한 앱, 실패 단계, 오류 메시지를 남겨주세요. 로그를 공유할 때 사용자 이름·개인 경로를 지우고, 연구자료나 API 키가 포함될 수 있는 설정 파일 전체는 올리지 마세요.

## 고급 설치

압축 해제 폴더의 PowerShell에서 다음처럼 실행할 수 있습니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 `
  -Language ko -Client claude `
  -PythonPath "C:\Python312\python.exe" `
  -StataHome "C:\Program Files\StataNow19" -Edition be
```

`-Language ko` 또는 `-Language en`으로 언어 선택을 생략할 수 있습니다. Python 직접 실행은 `--language ko|en`을 지원합니다. 두 앱은 `-Client both`, Codex만은 `-Client codex`입니다. `-ClaudeConfig "C:\path\claude_desktop_config.json"` 또는 `-CodexConfig "C:\path\config.toml"`로 실제 설정 파일을 지정할 수 있습니다. `-InstallDir`와 `-WorkDir`로 설치·분석 폴더를 지정합니다.

`-NonInteractive`는 질문 없이 실행하며 충돌이나 선택이 필요하면 실패합니다. 이때 언어를 생략하면 한국어이며, `-Client` 생략 시 기존 동작과 같이 Codex만 등록합니다. `-ReplaceExisting`은 선택한 앱의 기존 stata-local 교체에 명시적으로 동의하는 옵션입니다.

런처는 이번 PowerShell 프로세스에만 ExecutionPolicy Bypass를 적용하며 PC의 영구 실행 정책은 바꾸지 않습니다. 조직 정책으로 실행이 금지되면 관리자에게 문의하세요.

## 실행 범위

서버는 사용자 권한으로 Stata 명령을 실행합니다. 원자료·코드·로그를 GitHub에 자동 업로드하지 않습니다. AI 앱이 요청해 반환된 분석 결과와 그래프는 해당 앱에 전달됩니다. 설치 검사는 별도 세션에서 수행합니다.

## 개발자: 설치 ZIP 생성

저장소의 installer 폴더만으로는 설치할 수 없습니다. 저장소 루트에서 실행합니다.

```powershell
python -m build
python scripts/package_installer.py --dist dist
```
