# Stata MCP 자동 설치 — Windows / Codex

## 준비

- 정상 실행되는 Stata와 라이선스. 검증 환경: StataNow 19.5 BE.
- 64비트 Python 3.11 이상. 검증 환경: Python 3.12.
- 같은 Windows PC의 Codex 앱, 패키지 다운로드를 위한 인터넷 연결.
- GitHub 비공개 저장소에 접근 가능한 계정.

## 설치

1. GitHub Releases에서 `stata-mcp-0.1.3-windows-setup.zip`을 받습니다.
2. ZIP을 마우스 오른쪽 버튼으로 눌러 **모두 압축 풀기**를 선택합니다.
3. 압축을 푼 폴더에서 **설치.cmd**를 더블클릭합니다. `install.cmd`도 같은 기능입니다.
4. Stata가 여러 개이면 사용할 버전을 선택합니다. 자동 탐색되지 않으면 Stata 설치 폴더를 선택합니다.
5. 기존 `stata-local` 설정이 다르면 경로와 교체 안내가 표시됩니다. 교체할 때만 `Y`를 입력합니다. 다른 MCP와 사용자 설정은 보존하고 원본을 백업합니다.
6. 회귀분석·그래프 검사와 설정 등록이 끝나면 완료 안내가 나옵니다.
7. Codex를 완전히 종료했다가 다시 실행하고 **새 대화**에서 아래처럼 요청합니다.

> stata-local의 stata_status 도구를 호출해서 연결 상태를 확인해 줘.

최종 도구 호출은 Codex에서 확인해야 합니다. 설치기의 검사는 같은 MCP 프로토콜을 사용하는 독립 클라이언트로 수행합니다.

Python이 없으면 설치 안내를 표시하고 중단합니다. Stata와 Python 본체는 자동 설치하지 않습니다. Python을 설치했다면 설치기를 다시 실행하세요. 관리자로 실행할 필요는 없습니다.

## 설치 위치와 재실행

- 서버 환경: `%LOCALAPPDATA%\StataMCP\envs\0.1.3`
- Codex 설정: `%CODEX_HOME%\config.toml`, CODEX_HOME이 없으면 `%USERPROFILE%\.codex\config.toml`
- 분석 폴더: `%USERPROFILE%\Documents\StataAnalysis`
- 예제 검사 산출물: 분석 폴더의 `installation-check` 아래
- 설치 결과: `%LOCALAPPDATA%\StataMCP\installation-result.json`
- Claude Desktop 설정 예시: `%LOCALAPPDATA%\StataMCP\claude-desktop.local.json`

성공한 뒤에는 다운로드한 ZIP과 압축 해제 폴더를 지워도 됩니다. 위 서버 환경과 Python 본체는 유지해야 합니다. 같은 버전 설치기를 다시 실행하면 환경을 재사용하고 같은 Codex 설정은 중복 추가하지 않습니다. 새 버전은 별도 환경에 설치하며 이전 환경을 자동 삭제하지 않습니다.

Claude Desktop에는 생성된 JSON의 `mcpServers.stata-local` 항목을 기존 설정에 합쳐 사용합니다. 이 설치기는 Claude 앱 설정을 자동 변경하지 않으며, Claude 앱 실제 연결은 아직 미검증입니다.

## 오류 대응

- Python을 찾지 못함: Python 3.12 64비트 설치 후 재실행합니다. 별도 위치라면 아래 `-PythonPath`를 사용합니다.
- Stata를 찾지 못함: `utilities\pystata`와 `StataBE-64.exe`가 있는 Stata 설치 폴더를 선택합니다.
- 라이선스 오류: Stata 단독 실행을 먼저 확인합니다.
- 패키지 설치 오류: 인터넷·프록시·회사 정책을 확인하고 재실행합니다. 보안 설정을 끄지 마세요.
- 설정 문법 오류: 원본 설정은 덮어쓰지 않습니다. 안내된 `config.toml` 오류를 먼저 수정합니다.
- 설치가 강제로 종료됨: 다른 설치 창이 없는지 확인한 뒤 설치 폴더의 `install.lock`을 제거하고 재실행합니다. Codex 설정 옆 `.stata-install.lock`도 실제 설치가 진행 중이 아닐 때만 제거합니다.
- 앱에서 도구가 없음: Codex 완전 종료 후 새 대화를 엽니다. 조직 정책으로 로컬 MCP가 제한된 경우 관리자에게 문의합니다.

런처는 이번 PowerShell 프로세스에만 `ExecutionPolicy Bypass`를 적용해 동봉 스크립트를 실행합니다. PC의 영구 실행 정책을 변경하지 않습니다. 조직 정책으로 실행이 금지되어 있다면 우회하지 말고 관리자에게 문의하세요.

## 고급 설치

압축 해제 폴더의 PowerShell에서 필요할 때 경로를 지정할 수 있습니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 `
  -PythonPath "C:\Python312\python.exe" `
  -StataHome "C:\Program Files\StataNow19" -Edition be `
  -InstallDir "$env:LOCALAPPDATA\StataMCP" `
  -WorkDir "$env:USERPROFILE\Documents\StataAnalysis"
```

`-NonInteractive`는 질문 없이 실행하고 선택·충돌이 필요하면 실패합니다. `-ReplaceExisting`은 기존 stata-local 항목 교체에 명시적으로 동의하는 옵션입니다. `-CodexConfig`로 별도 설정 파일을 지정할 수 있습니다. 설치를 다시 실행해도 실제 Stata 연결 검사를 수행합니다.

## 실행 범위

서버는 사용자 권한으로 Stata 명령을 실행합니다. 원자료·코드·로그를 GitHub에 업로드하지 않습니다. Codex가 요청해 반환된 분석 결과와 그래프는 AI 앱에 전달됩니다. 설치기의 회귀 검사는 Stata 내장 auto 예제와 별도 세션만 사용합니다.

## 개발자: 설치 ZIP 생성

저장소의 installer 폴더만으로는 설치할 수 없습니다. 릴리스 ZIP에는 빌드된 wheel과 검증용 package.json이 함께 들어 있습니다. 개발자는 저장소 루트에서 다음을 실행합니다.

```powershell
python -m build
python scripts/package_installer.py --dist dist
```
